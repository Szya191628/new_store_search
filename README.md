# 本地新店拓客雷达 MVP（抖音买单 + 豆包找店）

面向本地生活服务商团队的内部自用拓客工具：从企查查/天眼查/爱企查/探迹导出的本地新注册个体户数据中，自动过滤住宅电商与车队空壳户、识别代账号码、通过高德地图 100 米 POI 围栏与 Playwright 队列核验抖音/美团空白状态，输出 S/A/B 三级线索与定制话术至响应式 Web 管理看板（支持电脑端电销 + 手机端扫街）。

## 1. 快速启动（推荐 Docker Compose）

```bash
cp .env.example .env
# 编辑 .env，填写 MYSQL_PASSWORD 与高德 API Key（也可启动后在后台网页填写）
docker-compose up -d --build
```

启动后访问 `http://服务器IP:8000`：
- 默认管理员账号：`admin` / 口令 `123456`
- 默认示例销售账号：`sales1` / `1234`、`sales2` / `1234`

## 2. 本地 Python 直接运行（连接现有 MySQL）

```bash
pip install -r requirements.txt
playwright install chromium
cp .env.example .env
# 在 .env 中填入你的 MySQL 主机、端口、库名、账号密码（系统首次启动会自动建表）
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

## 3. 核心业务规则说明

1. **实体店清洗与双轨标签**：
   - 保留含“路/街/道/号/铺/底商/商场/市场/一层”等临街与商业体特征的新店，剔除纯住宅网店、网约车、货运与全国连锁品牌。
   - 自动打标 **【到店消费型】**（餐饮、茶饮烘焙、丽人、洗浴足疗、休娱健身）与 **【便民实体型】**（五金、建材、汽修、便利零售等）。
2. **全局去重与代账号码识别**：
   - 按“统一社会信用代码（或店名+地址）”全局去重，绝不重复入库。
   - 同一手机号关联 `>= 2` 家不同个体户时，自动标红为 **⚠️ 疑似代账/中介电话**，保留门店并归入“建议直接线下扫街”。
3. **两级漏斗核验与不卡死兜底**：
   - 第一级：高德官方 API 地理编码 + 周边 100 米 POI 字号模糊匹配。
   - 第二级：Playwright 慢速队列核验抖音与美团状态；若触发滑块验证码自动降级为 `manual_review`，看板提供【查抖音】【查美团】【问豆包（自动复制检索词）】【高德导航】一键快查按钮。
4. **运行自动化测试**：
   ```bash
   python3 -m unittest discover -s tests -v
   ```
